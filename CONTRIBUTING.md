# Contributing to Delivery Decision

Thank you for your interest in contributing!

## Ways to Contribute

### Report a Bug 🐛
Open an Issue with:
- Clear description
- Steps to reproduce
- Your Android version

### Request a Feature 💡
Open an Issue with:
- Feature description
- Why it would be useful

### Submit Code 🔧

1. Create a new branch
2. Make your changes
3. Test thoroughly
4. Create a Pull Request

## Code Style

- Use Kotlin official conventions
- Clear, descriptive names
- Explain *why*, not *what*
- Keep functions small

## Questions?

Open an Issue and we'll help!
